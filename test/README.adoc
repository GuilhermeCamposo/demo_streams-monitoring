= Testing Scenarios

== Using the applications

This demo comes with two applications that simulate a consumer and producer relationship. These applications can be run using a terminal by following the instructions below:

=== Get the certificate for TLS connection

To connect the applications from outside the OpenShift cluster you first need the certificate for the TLS connection:

----
PROJECT=streams

oc extract -n $PROJECT secret/my-cluster-cluster-ca-cert --keys ca.crt --to /tmp/
keytool -keystore /tmp/client-truststore.jks -alias CARoot -import -file /tmp/ca.crt -storepass kafka1 -noprompt
----

The keystore will be used by the applications to trust the certificate in the connection.


=== Starting the Producer

----
PROJECT=streams
export PRODUCER_PWD=$(oc get secret producer -n $PROJECT  -o jsonpath='{.data.password}' | base64 -d )
export BOOTSTRAP_URL=$(oc get route my-cluster-kafka-bootstrap -n $PROJECT -o jsonpath='{.spec.host}'):443
export REGISTRY_URL=$(oc get route registry-app -n $PROJECT  -o jsonpath='{.spec.host}')

mvn clean quarkus:dev 
----

=== Starting the Consumer

----
PROJECT=streams
export CONSUMER_PWD=$(oc get secret consumer -n $PROJECT -o jsonpath='{.data.password}' | base64 -d )
export BOOTSTRAP_URL=$(oc get route my-cluster-kafka-bootstrap -n $PROJECT -o jsonpath='{.spec.host}'):443
export REGISTRY_URL=$(oc get route registry-app -n $PROJECT  -o jsonpath='{.spec.host}')

mvn clean quarkus:dev 
----

=== Testing


==== Quotes

First monitor the stream output:

----
curl  http://localhost:8080/quotes
----

Then start sending requests:

----
curl  http://localhost:8080/quotes/request -X POST
----


==== Movies

This use case examplifies the use of Schema Registry.

Consumer:
----
curl -N http://localhost:8081/consumed-movies
----

Producer:
----
curl --header "Content-Type: application/json" \
  --request POST \
  --data '{"title":"The Shawshank Redemption","year":1994}' \
  http://localhost:8080/movies

curl --header "Content-Type: application/json" \
  --request POST \
  --data '{"title":"The Godfather","year":1972}' \
  http://localhost:8080/movies

curl --header "Content-Type: application/json" \
  --request POST \
  --data '{"title":"The Dark Knight","year":2008}' \
  http://localhost:8080/movies

curl --header "Content-Type: application/json" \
  --request POST \
  --data '{"title":"12 Angry Men","year":1957}' \
  http://localhost:8080/movies
